# CogniBase

AI study and exam prep. Upload lecture material, then study from generated guides, flashcards, mind maps and slides, or ask questions grounded in your own sources.

Built with Next.js, Prisma, Supabase and Gemini.

## Development

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run lint
```

Copy `.env.example` to `.env.local` and fill in the values. See `AGENTS.md` for working rules and `cognibase-architecture.md` for how the pieces fit together.
